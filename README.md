# 🏆 FPL AI Assistant

Automatisk poängprognos och **Optimalt Wildcard-lag (£100m budget)** fram till **Omgång 15**.

---

## 📊 Filer i projektet

* **`fpl_predictions.csv`**: Innehåller den kompletta databasen med alla spelare, deras förväntade poäng ($xP$) och matchsvårighet (FDR) fram till GW15.
* **`top_players.md`**: En uppdaterad topplista över de bästa valen i varje position.

---

*Databasen och prognoserna uppdateras automatiskt via GitHub Actions varje natt.*
